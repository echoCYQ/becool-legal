2常见问题

内购 / 会员没有到账怎么办？
通常在支付成功后会自动到账。若未到账，请在「我的 → 会员」里点击「恢复购买」；仍无效请重启 App 或稍后再试，也可发邮件联系我们并附上订单号。
订阅如何取消或申请退款？
订阅由 Apple 处理，开发者无权操作。请在 iPhone「设置 → Apple ID → 订阅」中取消；退款请通过 App Store「报告问题」提交申请。
待办 / 日程为什么没有多设备同步？
请确认已登录同一账号，并在「我的 → 数据面板」开启云端同步；同时检查网络与账号登录状态。离线产生的修改会在联网后自动合并上传。
苹果日历 / 提醒事项如何与本 App 互通？
在「我的 → 苹果同步」里开启授权，即可聚合展示系统日历与提醒事项。相关数据仅保存在您的设备与 iCloud 中。
桌面小组件不显示或数据不更新？
请在桌面长按 → 添加「倍刻List」小组件后，打开一次 App 让数据刷新；若仍异常可重启手机或重新添加组件。
数据如何备份与恢复？
在「我的 → 数据面板」可导出本地备份文件，或使用云端备份与恢复，方便换机迁移数据。
忘记账号密码 / 想注销账号？
可通过注册邮箱找回密码；如需注销账号，请发送邮件说明，我们会在核实身份后协助处理，并删除相关数据。
