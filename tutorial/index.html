01

界面导览与底栏自定义

Navigation入口：全局面

打开 App，底部是一条胶囊导航栏，默认六个位置：统计、待办、效率、探索、百宝袋、我的。其中「效率」「探索」「百宝袋」是文件夹——点开弹出悬浮面板，里面收纳着更多模块；再点一下或下拉即可收起。

六个槽位里都有什么

  • 统计：首页报表，各模块数据汇总（第 09 章）。
  • 待办：任务清单，最高频入口（第 02 章）。
  • 效率（文件夹）：备忘录、番茄钟、计划、日历、倒数日、习惯（第 03–08 章）。
  • 探索（文件夹）：旅程、待办圈、打卡搭子、计划搭子、宠物、表盘工坊（第 18–20 章）。
  • 百宝袋（文件夹）：健康、进度条、倍刻环、记账、心情、收集单、复盘、活动、快捷指令中心等（第 10–17、21 章）。
  • 我的：账号、会员、通知中心与全部设置（第 24 章）。

手把手：把常用模块放上主栏

  1. 点底栏最右侧 我的。
  2. 在「设置中心」里点 外观与布局（主题、待办视图、底栏导航、日历视图、图标都在这一类）。
  3. 点 底栏导航 进入设置页。
  4. 拉到 底栏设置 区：勾选决定哪些栏目显示，按住左侧 ≡ 拖动排序。底栏最多直接显示 7 个栏目，多出来的可新建自定义文件夹归类收纳；「我的」固定在最后，保证设置入口始终可达。
  5. 同一页还能选导航栏形态：「悬浮胶囊」（全机型，经典底栏 + 文件夹收纳）或「苹果原生」（iOS 26+，液态玻璃 Tab Bar + 中控台）。
  6. 返回即生效——底栏布局完全随你的习惯来。
开启「悬浮胶囊也启用中控台」后，长按底栏「我的」即可唤出中控台快速切页。
iOS 26 及以上还可以体验苹果原生的液态玻璃 Tab Bar 形态，在设置里切换导航样式。
02

待办：新建 · 配置 · 手势 · 多视图

Todo入口：底栏「待办」

待办是倍刻List 的心脏：一条待办从新建到完成，中间每个配置项都能玩出花。本章把「新增待办」表单每一个字段拆开讲透，配上真实截图。

先认门：待办页长什么样

  • 顶部横幅：「完成 37 / 150 项」实时进度条，打气用。
  • 周视图横条：一周七天的「已完成/总数」，点任意一天按天过滤。
  • 类目筛选：全部 / 工作 / 学习 / 生活… 横滑切换。
  • 条目行：圆圈打勾、旗标优先级、截止/提醒图标、行尾 ⋯ 菜单。
  • 右下 ＋：新建入口，本章的主角。

手把手：新建一条待办（最小路径 3 步）

  1. 点右下角粉色 ＋，弹出「新增待办」表单（键盘自动弹起）。
  2. 写待办内容，例如「周五前交季度报表」。
  3. 点底部 ✓ 添加待办——完事！其余配置全是可选。
没填完想退出？直接下滑，App 会问「放弃修改 / 继续编辑」，内容不会误丢。

表单逐项配置详解

① 待办内容说明
干什么任务标题，支持多行：第一行是标题，换行可以接着写细节
小细节表单一打开键盘就自动弹起并聚焦这个输入框，不用先点一下
② 类目说明
内置 5 类📌 默认 / 💼 工作 / 📚 学习 / 🏠 生活 / 💪 健康，点按选择
自定义类目点类目行末尾 ＋：搜索式新增——先联想已有/历史类目，防止手滑建重复
删自定义类目自定义类目右侧有 ✕；删除只删类目标签，已有待办不受影响，误删还能在「历史新增」里恢复
调整顺序最右侧 ↕ 按钮进「类别排序」页，拖动重排，待办页筛选行同步生效
③ 上级待办说明
干什么把这条挂到另一条待办下面，组成父子层级——「写年度总结」下挂「收集数据」「写初稿」「排版」
怎么配点这一项弹出选择器，搜/选一条现有待办当爸爸；默认「不挂靠（顶层待办）」
注意旅程产生的待办投影不挂层级（层级在旅程域没有承载，挂了会假保存）
④ 归属计划说明
干什么把待办挂到某个「计划」（第 05 章）下，完成后自动推进计划的步骤进度
怎么配点选器里挑一个计划；还没建计划会提示「还没有计划」
⑤ 优先级说明
三档低 / 中 / 高；「高」在列表里带一面红色小旗，一眼识别
建议一天最多 3 面红旗，多了等于没有优先级
⑥ 颜色说明
干什么给这条待办一个专属底色，列表里一眼分区
怎么配默认 / 粉 / 紫 / 蓝 / 青 / 绿 / 黄 / 橙 / 红 9 个圆点，或点虚线「＋」自定义任意色
不透明度颜色下方的滑杆（0–100%）：调低是淡淡的底色，调高是浓郁的色块
⑦ 截止与重复说明
截止时间打开开关，选日期 + 时间；列表里逾期自动标红「已逾期」
重复设「每 N 天重复一次」：从创建日起每间隔 N 天再次出现，适合周期性任务
把后面的重复
也显示在日历里		开＝日历按重复规则铺出后续每一次（带 ⟳ 标记的只读预览）；关＝只在到期日当天显示
⑧ 提醒说明
表单内开「提醒」开关，选到点通知的时间
列表快捷行内铃铛不用进表单：一键「1 小时后 / 今晚 20:00 / 与截止同时」
双保险可「写入苹果提醒事项」，到点由系统提醒再兜一层
⑨ 番茄联动说明
不联动默认，纯任务不管专注
联动（正计时）从 0 往上计、手动结束；不会因计时自动完成待办，需手动勾选
专注满目标自动完成配「目标专注 N 分钟」；倒计时模式下本轮时长按目标分钟、到点响铃，累计满目标自动勾掉待办
⑩ 备注 / 照片 / 附件说明
备注「补充一些细节…」多行文本，链接、地址、注意事项随便写
照片最多 3 张；保存在本机并同步到你自己的 iCloud
文件附件仅保留在本机，不会上传云端
⑪ 协作口径说明（挂到共享计划时出现）
全员共享一套这里的修改会同步给计划的所有成员
每人一套勾选完成只记录你自己的进度，不影响其他成员
房主只读房主开启只读时：不可修改、不可勾选完成，但可从你的列表移除并撤回

建好后去哪看：截止 · 重复 · 日历联动实拍

以最常用的「设截止 + 每天重复 + 铺进日历」为例，完整走一遍：

  1. 新建待办写上「每天喝水 2L」，打开截止时间开关，选「2026 年 9 月 27 日 · 09:00」。
  2. 重复规则点选每天（也可选每周 / 每月）。
  3. 关键开关：把后面的重复也显示在日历里——开＝日历按重复规则铺出后续每一次（带 ⟳ 标记，只读预览）；关＝只在到期日当天显示。
  4. 点添加保存。
  5. 回到待办列表：条目上直接带 「每天」重复徽章 和到期时间。
  6. 打开日历：月历格子里出现白色方点 = 重复待办，后续每一天都铺开显示；图例在月历下方（圆点＝日程、胶囊＝多天、方点＝待办、白方点＝重复待办）。
  7. 月历下方「接下来 3 天」面板汇总当天日程 / 计划 / 习惯 / 待办条数，点 ＋ 可直接往当天加内容。
后续铺出来的重复实例是只读预览：提醒你别漏，但完成动作只能点在「源实例」（到期日当天那条）上。

视图与完成样式：待办页的「装修间」

  1. 入口：我的 → 设置中心 → 外观与布局 → 待办视图。
  2. 勾选视图：今天 / 最近 7 天 / 四象限 / 看板——勾选后待办页顶部多出对应页签，装不下可左右滑动；「列表」是基础视图恒开启。
  3. 调整顺序：拖动 ≡ 手柄或点右侧上下箭头，序号即时更新。
  4. 完成样式：标准（默认不打删除线）；删除线 / 强淡化 / 收缩淡化为 Pro 会员样式。
视图干什么
今天只看今天要做的与今天完成的
最近 7 天按天分组看接下来一周的安排
四象限按重要 / 紧急拆成四格，先做哪件不再纠结
看板按类目分列浏览，竖列优先，区域不够再横向展开

列表里的日常操作

  • 完成：点行首圆圈打勾；完成样式按上节设置渲染。
  • 看详情：点条目文字弹详情卡，底部一键「标为已完成 / 编辑」。
  • 快速提醒：行内铃铛「1 小时后 / 今晚 20:00 / 与截止同时」。
  • 编辑 / 删除：详情卡点「编辑」，或行尾 ⋯ 菜单删除。
  • 批量处理：开「单选」模式逐条勾选，批量完成 / 清理。
  • 临时切换视图：筛选行最右侧的视图图标（▦）点开出下拉即换；长期显隐与顺序在「我的 → 外观与布局 → 待办视图」里调。
  • 时间线：按「添加于 / 到期」时间轴浏览，滑过来点确认。
  • 关系图：父子层级画成图谱，拖动高亮、双指缩放。
  • 导出手帐：今天 / 本周 / 全部范围 + 已完成 / 未完成过滤 + 夜幕 / 奶油主题，生成长图分享。
待办是枢纽：挂「进度条」自动汇总完成度（第 11 章）；开番茄联动让专注自动打勾（第 03 章）；挂计划计入 OKR 进度（第 05 章）。
03

番茄钟：专注与科目

Pomodoro入口：底栏「效率」文件夹

经典番茄工作法：专注 25 分钟，休息一下，再出发。

手把手：开始一次专注

  1. 选择模式：🍅 专注 / 🍵 小憩 / 🛌 长休。
  2. （可选）点「🔗 关联一个待办」，这段专注就记到那条待办头上。
  3. （可选）点「📚 选择科目」，按科目统计学习时长。
  4. 点中央大圆环下方的 ▶ 开始；左键重置、右键跳过本段。
  5. 到点自动提醒进入休息，完成时有庆祝动效。

逐项配置详解

配置说明
关联待办点开始前的「🔗 关联一个待办」，这段专注记到那条待办头上；配合待办「番茄联动」可满目标自动打勾（第 02 章 ⑨）
关联习惯关联一个习惯，专注满目标自动打卡（第 06 章）
选择科目按科目统计学习时长；科目支持新建 / 子科目 / 图标 emoji / 配图（如「数据结构」）
智能时长按关联待办 / 习惯的番茄目标、科目默认时长、所属类目自动配倒计时；什么都没关联时按全局专注时长走
时长设置页面底部「时长设置（分钟）」手动调；智能时长基础上还能「微调」
计时环样式经典圆环外还有黏土农场、雨夜便利店等主题；仅「墨笔」计时环与「星光爆散」到点特效免费，其余为 Pro 专属；特效缩放非会员固定「标准」
白噪音内置白噪音 + 「下载更多」（Pixabay 免费音效）+ 导入本地音频（mp3 / m4a / wav）
背景图可换计时背景；有背景图时遮罩最低 35% 保证读时清晰；删除自定义背景只移除本机文件，不影响内置背景
同步到系统日历开启后专注完成，整段时间记入系统日历（需授予日历权限，未授予会提示去系统设置）
横屏 StandBy充电横放进入床头钟模式

专注完成时怎么记

  1. 到点响铃，弹出「专注 N 分钟，选择怎么记录这段时间」。
  2. 选 ✅ 算进专注时间 计入统计；也可选「提前结束」按实际时长记。
  3. 如果开了「同步到系统日历」，这段时间同时写进系统日历。
「小课堂自习」：从待办圈的课堂进入自习，坐下即开始——「已就坐，开始就是自习」，中途还会提示「专心中… 别偷看手机哦」。

记录页：查看与补记

  • 顶部切到 📋 记录：今日 / 本周 / 累计分钟数 + 专注分布（类别 / 待办 / 科目三维度）。
  • 点任意一条记录可编辑：修改状态（完成 / 提前结束 / 中途放弃）、拖时长滑杆、改类别归属；漏记的也能补。
  • 支持导出专注报告。
04

日历：月历与日视图

Calendar入口：底栏「效率」文件夹

日历把日程、计划、待办、倒数日放进同一张月历（带农历）。某天有多少事，不用点进去就知道。

读月历

  • 每个格子直接显示当日日程 / 计划 / 待办条目，放不下折叠为「+N」。
  • 日期左上角是农历；今天高亮圆圈。
  • 倒数日跨天时画成连续色条，目标日自动高亮。
  • 右上角可切换月历密度（放大 / 紧凑）与议程样式。
  • 格子里的标记：圆点＝日程、长胶囊＝跨多天事项、方点＝待办、白色方点＝重复待办的铺开预览。
  • 月历下方「接下来 3 天」面板：按天汇总日程 / 计划 / 习惯 / 待办，右侧 ＋ 直接往当天加。

手把手：安排某一天

  1. 点月历上的任意日期，展开日视图面板。
  2. 顶部是当日日程，右侧 ✏️ 编辑、🗑 删除。
  3. 「到期待办 X/Y」里的待办可以直接点方框勾选完成，不用切页。
  4. 底部三个按钮：添加日程、添加待办、旅程（把行程段排到这天）。
  5. 点「收起」或下滑关闭面板。
05

计划：OKR 目标管理

Plan入口：底栏「效率」文件夹

计划模块用 OKR 思路管目标：定一个计划（O），拆成若干步骤作为关键结果（KR），按步骤推进，完成率自动算。

手把手：建一个计划

  1. 计划页点右下角 ＋，打开新建计划表单。
  2. 填计划名称，例如「学会弹尤克里里」。
  3. 选分类、优先级、周期（季度 / 年度）。
  4. 逐条添加步骤——它们会作为关键结果展示在卡片上。
  5. （可选）关联待办：把执行层面的待办挂进来。
  6. 保存后回到列表，卡片上实时显示进度；点步骤即可逐条勾掉。

表单逐项配置详解

字段说明
计划名称表单顶部输入框，提示语「例如：学会弹尤克里里」
上级计划计划可以套计划，组成目标树——大目标下挂子计划
分类 / 优先级与待办同套类目体系；优先级影响排序
周期季度 / 年度，到期自动统计
步骤逐条添加，将作为关键结果展示在卡片上，逐条勾掉推进进度
关联待办把执行层的待办挂进来，待办完成度反哺计划进度
量化进度设置给计划配数字化目标量（如 30 次 / 100 页）
进度条样式卡片上的进度视觉，标注「该进度条样式为会员专属，开通 Pro 后即可在计划卡片与录入弹窗使用」
粗细 / 动效全局设置，对所有计划生效
备注（可选）写背景、动机、注意事项
关闭表单时若有未保存修改，会弹「放弃修改 / 继续编辑」确认，不丢草稿。

更多

  • 聚焦视图：只看当前最重要的事，减少干扰。
  • 多维筛选：全部 / 未开始 / 进行中 / 已完成 / 已逾期，按时间与状态过滤。
  • 导出：计划进展可生成分享图。
计划会自动出现在「进度条」模块的来源里，也能挂到桌面「计划」小组件上随手推进。
06

习惯：打卡与连击

Habit入口：底栏「探索」文件夹

习惯模块把「每天坚持一下」变成看得见的连击：连击天数、最长纪录、近 30 天完成率、翻面热力图。

手把手：建一个习惯

  1. 习惯页点 ＋ 打开新建表单。
  2. 填习惯名称，例如「每天喝够 8 杯水」。
  3. 选图标：内置 emoji 库，或自己输入一个 emoji / 文字。
  4. 设打卡周期：每天 / 每 N 天（如每 3 天 = 第 1、4、7…天）/ 每周自定义。
  5. （可选）设每日打卡时段：早 / 中 / 晚逐项打卡，时段名可自定义，全部打完即当日达标。
  6. （可选）开番茄联动：专注满目标分钟数自动打卡，学习类习惯特别合适。
  7. 保存。之后每天到点：点习惯卡片 → 打卡面板（顶部显示「今天 · 日期 · 周几」）→ 按时段逐项点打卡，全部打完显示「已达标」。

表单逐项配置详解

字段说明
习惯名称提示语「例如：每天喝够 8 杯水」
图标内置 emoji 图标库点选，或「输入自定义 emoji / 文字」
打卡周期每天 / 每 N 天（从创建日起每间隔对应天数为应打卡日，例如「每 3 天」= 第 1、4、7…天）/ 每周自定义（指定周几）
每日打卡时段按时段打卡：每天按 早 / 中 / 晚 逐项打卡，时段名称回车即可自定义（如「睡前」），全部打完即当日达标
每日打卡次数一天打几次才算达标（与时段制二选一）
关联科目纳入番茄钟的科目统计；「不关联（不纳入科目统计）」
番茄联动专注满目标自动打卡，配「目标专注 N 分钟」；学习类习惯的自动化神器
热力图显示范围一周到一年自由调节（按周数），只影响这个习惯的翻面热力图与导出

打卡面板里的操作

  • 点错打卡？撤销一次回退；打卡日志查看历史每一次。
  • 卡片长按 / 详情里可置顶重要习惯、编辑参数。
  • 忘了打卡用补卡补记过去的日期。
  • 删除习惯会移入回收站（不是真删），可在「我的 → 回收站」随时恢复。
  • 打卡记录支持导出「我的习惯册」：总打卡、最佳连续、近 N 周热力，分页生成分享图。

「记一笔」表单逐项配置详解

字段说明
收支类型支出 / 收入 / 转账；转账可填手续费（从转出钱包扣），手续费会额外生成一条支出流水并与本次转账关联
金额专属数字键盘，输入即「快速记一笔」
分类餐饮 / 交通 / 购物…；分类用完会提示去「账单设置 › 分类管理」添加
钱包 / 支付方式储蓄卡 / 信用卡 / 微信支付 / 支付宝 / 其他，多钱包分开记
日期默认今天，可选昨天或任意日期补记
优惠金额（可选）实付与原价分开记，省了多少钱有据可查
备注「写一句备注（可选）」
标签#标签 归类，搜索时可按标签过滤
报销标记为可报销，月底在报销视图一键汇总
不计收支勾上后该笔只留流水、不计入收支统计（如账户间挪钱）
截图 / 小票随这笔账单保存，仅在本机
关联旅程 / 计划归集到某次旅行或某个计划下，取消关联随时可点
更多选项表单默认精简；「更多选项（日期 · 备注 · 支付方式 · 标签）›」点开全量字段
删除「删除这笔账单？」确认后按回收站口径软删，不会影响其他数据
放弃未保存就退出会问「放弃这笔记录？已输入的内容不会被保存」

更多能力

  • 统计与预算：分类洞察、月度统计、预算提醒（设预算：花得明白）。
  • 日历视图：按天看花了多少。
  • 搜索：按备注 / 分类 / 标签全文搜。
  • 快捷模板：常喝的咖啡存成模板，一键记。
  • 导入旧账单：支持微信 / 支付宝账单导入向导（含 OCR 识别），步骤见下方。
  • 导出：XLSX 表格导出，搬家不换本。
  • 报销：标记可报销账目，月底一键汇总。
  • 多账本 / 多钱包：不同场景分开记。

手把手：导入微信 / 支付宝旧账单

  1. 微信导出：微信 →「我」→「服务」→「钱包」→「账单」→ 右上角「···」→「导出账单」，选 CSV 或 XLSX，发送到本机。
    支付宝导出：支付宝 →「我的」→「账单」→ 右上角「···」→「开具交易流水证明」，选时间范围导出 CSV，发送到本机。

  4. 逐批确认：与已有账单重复（同单号 / 同指纹）的可选「仍导入 ✓」或「全部跳过」。
  5. 完成后点「去看看账单」。导错了也不怕：导入记录可在「账单设置 › 导入」整批撤销。
隐私三档自由选择：纯本地（默认，「账单仅保留在本机，不会上传云端」，换机前记得导出备份）→ 你的 iCloud（随全量备份，官方接触不到）→ 官方云同步（需阅读声明后手动开启，HTTPS 加密，随时可关）。

  • 打卡 1 个习惯：每日首次 +1 青蛙币。
  • 搭子打卡（空投）：搭子每次打卡，空投 +1 青蛙币。

手把手：玩转青蛙币罐

  1. 打开活动页，先完成「今日任务」清单里的事（完成待办、打卡习惯）——每完成一项，青蛙币「叮」地落进罐子。
  2. 倾斜手机：罐里的币会跟着滚动，像真的一样。
  3. 摇一摇手机：罐子有震动反馈，解压。
  4. 点明细：查每一枚币是哪件事赚来的。
  5. 攒够了去兑换勋章与小惊喜。
18

宠物：养一只小可爱

Pet入口：底栏「探索」文件夹
宠物是 Pro 会员功能：升级后才能领养、投喂小窝伙伴；Basic 仅本地保存与导出。

手把手：养第一只宠物

  1. 第一次进入宠物页，跟着领养流程挑一只合眼缘的小家伙。
  2. 回到宠物页：点 🐾 摸摸 跟它亲昵，点 💬 说话 听它回应。
  3. 正常用 App 就行——完成待办、专注、打卡都会变成它的成长值，名签下实时显示（如「闪耀 · 成长 268」）。
  4. 它还会把你当前的待办顶在名签下方，陪你一起惦记。
  5. 想再养？可以养多只，随时切换查看。
宠物也有桌面小组件（大号），不用打开 App 就能摸摸它（见第 22 章）。
19

搭子社交：一起坚持

Together入口：底栏设置开启

一个人坚持很难，那就拉个搭子。三个社交模块默认收在底栏设置里，想用就去「我的 → 底栏设置」打开（需登录账号）。

🤝 打卡搭子：开一个打卡营

  1. 打卡搭子页点 ＋ 创建小组。
  2. 填小组名称（例如「早起打卡营」），选个图标或输入自定义 emoji。
  3. 设打卡频率：一周 / 一个月内「N 天完成」；设打卡日历范围。
  4. 选打卡提醒：不提醒全靠自觉 💪 / 到点没打卡 30 分钟后给没完成的搭子补提醒 / 半小时后再提醒一次。
  5. （可选）关联我的习惯，打卡双计；群主还能上传竖版壁纸当打卡背景。
  6. 保存后把邀请发给朋友；搭子每次打卡，你还会收到青蛙币空投（第 17 章）。

🧑‍🤝‍🧑 计划搭子：凭码组队

  1. 创建者：在计划搭子页建一个计划，点「开启协作」生成邀请码。
  2. 朋友：同一页面选「凭码加入计划搭子」，输入邀请码加入。
  3. 双方在协作面板里各自推进、进度互见；有邀请时顶部会显示「『某某』邀请你加入『某计划』」。
  4. 误删不慌：删除的计划会进回收站，可一键「还原并加入」。

👥 待办圈：朋友的自习室

  1. 待办圈页先去添加好友。
  2. 逛逛公共课堂，或点「创建我的课堂」自建圈子。
  3. 在圈里看今日动态与好友的历史完成待办，互相「常做的事」里找同款任务。
  4. 还能去好友零食袋偷点零食（偷过会标记「已偷过」😄）；遇到不欢迎的内容可举报，拉黑后对方即从圈里移除。
搭子类功能需要双方都有账号；宠物也可以在圈里「藏起」不给别人看。
20

表盘工坊：戴上手腕

Watch Studio入口：底栏设置开启

手把手：设计一块表盘

  1. 打开「表盘工坊」，点 新建表盘（或在「我的表盘」里选一块点编辑）。
  2. 点 添加模块，把今日待办、习惯连击、专注时长等信息块放上去。
  3. 点按模块即选中，拖动调整位置；还能加粗、换配色。
  4. （可选）自定义照片背景——原图只保存在本机；分享给朋友时会自动降级为渐变背景。
  5. 点「在手表上试看效果」预览，满意后保存并关闭，同步成功会显示「已同步到手表 ⌚️」，当前启用的表盘带「使用中 💖」标记。
需要配对 Apple Watch 使用；没有手表也可以先在工坊里设计着玩。
21

快捷指令中心：一键直达

Shortcuts入口：底栏「百宝袋」

把常用操作做成 iOS 快捷指令或 Siri 口令：倍刻List 已内置 8 条系统级指令，对 Siri 说口令直接用；也可以把深链做成自己的快捷指令，挂到主屏幕、背面轻点、操作按钮或小组件上。

免设置：8 条系统已内置（Siri 直接用）

  • 这 8 条无需创建，已住进系统快捷指令 App：新建待办 / 今日未完成 / 打卡习惯 / 记一笔 / 开始专注 / 记录心情 / 写备忘录等。
  • 对 Siri 说「用倍刻List 新建待办」「用倍刻List 看今日未完成」「用倍刻List 打卡 + 习惯名」即可触发。
  • 在快捷指令 App 里搜索「倍刻」也能找到全部内置指令。

手把手：做一个「新建待办」桌面指令

  1. 打开「快捷指令中心」，找到「待办快捷指令 → 新建待办」。
  2. 点右侧 添加 / 去创建（预制指令显示「添加」，直接调系统分享表单安装；其余「去创建」= 自动复制链接并打开编辑器）。
  3. 在快捷指令 App 里把它添加到主屏幕（或绑定背面轻点 / 操作按钮）。
  4. 以后点桌面图标，直接弹出倍刻List 的新建待办窗口。

深链清单

  • 待办：新建待办 / 今日未完成 / 打开待办页。
  • 习惯：打开习惯页 / 直开某个习惯的打卡面板。
  • 记账：一键弹出记一笔（支持 ocr=clipboard 识别剪贴板截图文本预填）。
  • 每条都能先复制链接自己拼装；所有链接只在本机跳转，不联网、不收集数据。
22

桌面小组件与小组件工坊

Widgets入口：我的 → 小组件工坊

倍刻List 有一整套桌面小组件：待办勾选、习惯打卡、习惯热力、倒数日、计划、日历、宠物、旅程、统计、专注、时钟、年度进度……全部在「我的 → 小组件工坊」里管理。

手把手：把小组件放上桌面

  1. 打开「我的 → 小组件工坊」，浏览所有组件卡片。
  2. 长按某张卡片，查看添加到桌面的图文步骤。
  3. 按提示回到桌面，长按空白处 → 左上角「＋」→ 搜索「倍刻List」→ 选尺寸添加。
  4. 添加后长按组件 → 编辑小组件，配置展示内容（如倒数日选哪张卡片、习惯热力的时间范围）。

工坊里还能做什么

  • 点按卡片：预览样式、自定义背景与主题色。
  • 数据通道：查看每个组件的数据是否在线（App Group 共享缓存），异常一键「重载全部」。
  • 可交互：待办勾选、习惯打卡、摸摸宠物等组件支持桌面直接操作（卡片上标有交互数）。
  • 导入方案：别人搭配好的主题方案一键导入。

Mac 版与快捷键

macOS入口：Mac 客户端

倍刻List 也有 Mac 版：底部胶囊导航把全部模块平铺开（统计 / 待办 / 计划 / 旅程 / 待办圈 / 打卡搭子 / 计划搭子 / 进度条 / 活动 / 复盘 / 倍刻环 / 账单 / 收集单 / 我的），数据与 iPhone 同步。

键盘快捷键

快捷键作用
⌘ 1 – 4菜单栏快速切换主栏目
⌘ N「新建」当前页——在哪个页面就新建哪个模块的条目（如待办页 = 新建待办）
⌘ R手动刷新同步
iPad 外接键盘同样适用这组快捷键。

账号、同步与设置

Settings入口：底栏「我的」

账号与同步

  • 本地优先：核心数据默认存在本机，不强制登录、不上传。
  • 登录：「我的」页顶部账号卡登录（用户名 2–50 字符 + 密码），也支持 通过 Apple 登录；登录后待办 / 日程 / 倒数日 / 计划可多端同步；可绑定微信。
  • iCloud 同步：「我的 → 数据同步」开启后多设备自动同步，数据只进你自己的 iCloud。

常用设置入口（我的 → 设置）

  • 底栏设置：自定义导航栏目顺序与显隐（见第 01 章）。
  • 通知中心：集中管理待办提醒、打卡提醒。
  • 回收站：删除的习惯 / 计划 / 搭子计划都在这里，7 天内可还原。
  • 设置中心三大类：外观与布局（主题 / 待办视图 / 底栏导航 / 日历视图 / 图标）、数据与同步（健康数据 / 云端同步 / 微信绑定 / 备份恢复）、关于与帮助——先选大类再进具体功能，每个入口都显示用途说明。
  • 小组件工坊：桌面组件的统一管理台（见第 22 章）。
  • Pro 会员：解锁复盘周 / 月自选、进度条无限条数与皮肤图鉴、倍刻环主题色卡、待办删除线等。
  • 多语言：简体中文 / 繁体中文 / English。
  • 诊断与反馈：遇到问题一键导出诊断信息发给客服。
